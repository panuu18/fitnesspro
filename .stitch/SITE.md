# FitnessPro Site Constitution

## 1. Vision & Purpose
FitnessPro is a premium, high-energy mobile application (built in React Native) for tracking workouts, diets, and personal fitness achievements. The goal is to provide a sleek, motivating user interface that feels both futuristic and accessible.

## 2. Core Mechanics & Architecture
- **Tech Stack:** React Native (Expo) - generated initially as Stitch HTML/CSS screens for design approval, then translated.
- **Navigation:** Bottom tab bar navigation for primary screens (Dashboard, Workout, Nutrition, Profile).
