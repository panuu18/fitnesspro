An active workout tracking screen for logging exercises in real-time.

**DESIGN SYSTEM (REQUIRED):**
Use a strict dark mode theme with a Deep Charcoal (`#121212`) background and Dark Gray (`#1E1E1E`) cards. Primary actions and accents must use Electric Neon Green (`#39FF14`), and secondary elements should use Cyber Blue (`#00F0FF`). Use a clean, modern sans-serif font (Inter) with bold, punchy headings. All cards and buttons should have a soft 16px border radius. Use subtle neon glows for active elements instead of heavy shadows. Keep the layout spacious, modern, and highly legible. Text should be white or light slate.

**Page Structure:**
1. Top bar: Back button, Workout Title (e.g., "Leg Day Killer"), and elapsed time (e.g. 14:32).
2. Current Exercise: Large text showing the current exercise (e.g. "Barbell Squats") with a large visual indicator of sets completed (e.g. Set 3 of 5).
3. Input Area: Two large inputs for Weight (lbs) and Reps, with a massive Neon Green "Log Set" button.
4. History/Next: A smaller list below showing previous sets logged today, and what exercise is up next.
5. Bottom Navigation: Icons for Home, Workout, Nutrition, and Profile. (Workout should be highlighted).
