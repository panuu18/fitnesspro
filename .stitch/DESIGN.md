# Design System: FitnessPro

## 1. Brand & Vibe
Premium, high-energy, and modern. Designed to motivate users while maintaining a sleek, professional appearance. 

## 2. Global Tokens
- **Theme:** Dark Mode (strict)
- **Primary Color:** Electric Neon Green (`#39FF14`) for primary actions and accents.
- **Secondary Color:** Cyber Blue (`#00F0FF`) for secondary metrics and active states.
- **Backgrounds:** Deep Charcoal (`#121212`) for app background, Dark Gray (`#1E1E1E`) for cards/panels.
- **Text:** Pure White (`#FFFFFF`) for primary text, Light Slate (`#A0A0A0`) for secondary text.
- **Typography:** Modern, clean sans-serif (e.g., Inter, Roboto). Headings are bold and punchy.
- **Border Radius:** 16px (roundness: ROUND_SIXTEEN or ROUND_TWENTY_FOUR) for a soft, premium feel.
- **Shadows:** Subtle neon glows instead of harsh drop shadows.

## 3. Core Components
- **Cards:** Used heavily to group metrics (e.g., daily steps, calories burned). Use `#1E1E1E` background.
- **Buttons:** Large, pill-shaped buttons with the primary Electric Neon Green color.
- **Data Visualizations:** Use circular progress rings (activity rings) and sleek bar charts.

## 6. Design System Notes for Stitch Generation
**DESIGN SYSTEM (REQUIRED):**
Use a strict dark mode theme with a Deep Charcoal (`#121212`) background and Dark Gray (`#1E1E1E`) cards. Primary actions and accents must use Electric Neon Green (`#39FF14`), and secondary elements should use Cyber Blue (`#00F0FF`). Use a clean, modern sans-serif font (Inter) with bold, punchy headings. All cards and buttons should have a soft 16px border radius. Use subtle neon glows for active elements instead of heavy shadows. Keep the layout spacious, modern, and highly legible. Text should be white or light slate.
