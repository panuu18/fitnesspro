# FitChamp 🏆

Welcome to **FitChamp**! This repository contains the source code for our cross-platform fitness application, built to help you track your steps, meals, and climb the leaderboard.

🔗 **[Visit Our Website](https://fitpulse-pro.web.app)** - Start using FitChamp today!

## 📱 About The Project

FitChamp is a comprehensive health and fitness tracking application that works seamlessly across the web and mobile platforms. 

**Key Features:**
- **Step Tracking:** Monitor your daily steps and stay active.
- **Leaderboards:** Compete with friends and other users on the leaderboard.
- **Cross-Platform:** Available on the Web (Vite) and Mobile (React Native / Expo).

## 🚀 Tech Stack

- **Frontend:** React, React Native, Expo
- **Web Build Tool:** Vite
- **Backend & Deployment:** Firebase & Vercel
- **Styling:** React Native Web & SVG

## 🛠️ Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/fitnesspro.git
   ```
2. Navigate to the project directory
   ```bash
   cd fitnesspro
   ```
3. Install NPM packages
   ```bash
   npm install
   ```

### Running the App

**For Web:**
```bash
npm run web
```

**For Mobile (Expo Go):**
```bash
npm start
```

## 📦 Deployment

The app is configured for deployment on Firebase and Vercel. 

- To build for web: `npm run build:web`
- To deploy to Firebase Hosting: `npm run deploy:hosting`
- To deploy to Vercel: `npm run deploy:vercel`
